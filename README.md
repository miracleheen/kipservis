Уважаемая команда **КИП-Сервис**,

Хочу отметить, что тестовое задание представлено в двух вариантах реализации — на Java и на C#.

Согласно техническому заданию, решение должно было быть выполнено на C#. Как видно из моего резюме, моя основная специализация — Java, а с C# я работал ранее, во время учёбы в университете, и за прошедшее время многое успел забыть.

Чтобы не терять время на восстановление в памяти синтаксиса и экосистемы C#, я сначала реализовал задачу на знакомом мне стеке — Java/Spring, самостоятельно продумав архитектуру и логику решения. После этого перенёс реализацию на C#, для чего частично воспользовался помощью нейросети — в первую очередь для ускорения адаптации синтаксиса и работы с менее знакомыми инструментами экосистемы .NET (Entity Framework Core, ASP.NET Core).

Хочу подчеркнуть: язык программирования и вспомогательные инструменты — это средства достижения результата, а не самоцель. Я убеждён, что любой инструмент, включая C#, можно освоить по мере необходимости, и готов подтвердить это на практике.

В папке [images](#images) вы можете найти скриншоты тестирования API через Postman, подтверждающие корректную работу решения в соответствии с требованиями технического задания.
